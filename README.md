# ☢️ The Bunker Game

A real-time, AI-driven social deduction and survival game. 

Players are thrown into an apocalyptic scenario where a bunker only has room for exactly half of the group. Each player receives a unique, AI-generated role with a vital skill, a catastrophic fatal flaw, and a secret about someone else. After a tense face-to-face debate, the Room Host inputs the group's final decision on who survives—only to face the brutal, objective judgment of the Bunker's AI.

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI
* **Real-Time Communication:** WebSockets (asyncio)
* **AI Integration:** Google Gemini 3.5 Flash API
* **Frontend:** HTML5, TailwindCSS, Vanilla JavaScript
* **Infrastructure:** Docker, Docker Compose

## ✨ Key Features
* **Dynamic Role Generation:** Roles, flaws, and secrets are procedurally generated by Gemini based on the selected apocalyptic scenario.
* **Resilient WebSockets:** Custom auto-reconnect logic handles network drops without losing game state.
* **Tabletop Focus:** The Host acts as a game master, submitting the final verdict so players stay fully engaged in the actual conversation and arguments.
* **Objective AI Smackdown:** The AI mathematically pre-calculates the ideal survival team based on pure logic and compares it to the group's final choice, highlighting toxic synergies and fatal mistakes.

## 🚀 How to Run Locally

### Option A: Using Docker (Recommended for production/testing)
1. Clone the repository and navigate to the root folder.
2. Create a `.env` file based on `.env.example` and add your Google Gemini API Key.
3. Run the container:
   `docker-compose up --build`
4. Open `frontend/index.html` in multiple browser tabs to simulate players.

### Option B: Using Uvicorn (For rapid development)
1. Navigate to the `backend` folder and create your virtual environment.
2. Install dependencies: `pip install -r ../requirements.txt`
3. Make sure your `.env` file is located in the root folder.
4. Run the development server:
   `uvicorn app.main:app --reload --env-file ../.env`
